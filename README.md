#### Оптимизатор правил на OpenAI Agents SDK

Агентная система для автоматического улучшения правил риск-классификации на размеченных данных.

**Кратко:**

- `judge`-агент оценивает качество правила.
- generator-агент создаёт несколько beam-вариантов.
- Сначала используется greedy search.
- При плато качества включается beam search.
- На выходе пользователь получает оптимизированное правило.

**Что сделал:**

- Разработал multi-agent pipeline для оптимизации правил.
- Реализовал генерацию простых, LLM и комбинированных правил.
- Добавил автоматическую оценку качества вариантов.
- Реализовал стратегию поиска с переходом от greedy к beam.

**Стек:** Python, OpenAI Agents SDK, LLM, Prompt Engineering, Rule Optimization, Beam Search.

#### КСПЗ — агент иерархической классификации пользовательских запросов

Приложение для классификации пользовательских запросов по иерархии сервисов в банковском контуре.

**Кратко:**

- Около 100 000 строк пользовательских запросов.
- Тестовая выборка — 15 000 строк.
- F1 по категориям — 82%.
- Exact match по полному пути — 62%.
- RSS — около 200 MB.
- Нагрузочный тест — 48 req/s.
- Latency inference — около 200 ms на запрос.

**Что сделал:**

- Разработал retrieval-based решение для иерархической классификации.
- Реализовал гибридный поиск: dense retrieval, BM25, TF-IDF.
- Добавил KNN и top-k voting по каждому каналу.
- Реализовал fusion-логику выбора gold path.
- Настроил хранение словаря валидных путей и индексов.
- Реализовал самоактуализацию через API: добавление новых запросов, расширение словаря, обновление индексов.
- Проверил 6 гипотез: от тяжёлого bi-encoder + cross-encoder подхода перешёл к лёгкому retrieval + KNN решению.

**Стек:** Python, FastAPI, Qdrant, OpenSearch, PostgreSQL, GigaChat Embeddings, Dense Retrieval, BM25, TF-IDF, KNN, Fusion, Hierarchical Classification.
